# 메롱

Vite + React 로 만드는 게임/인터랙티브 사이트.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 미리보기
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가
빌드해서 GitHub Pages로 올립니다.

```bash
git add -A
git commit -m "변경 내용"
git push
```

`vite.config.js` 의 `base` 는 저장소 이름(`/testgame/`)과 같아야 합니다.
저장소 이름을 바꾸면 `base` 도 같이 바꿔주세요.

## 조작

- **PC** — 방향키 · WASD 이동, 건물 앞에서 `Space`, `C` 로 채팅
- 섬이 셋입니다 — **윗동네** · 가운데섬 · 아랫섬(구름카페 · 구름옷가게).
  섬끼리는 **미끄럼틀**로만 오갑니다. 오른쪽 분홍은 가운데↔아래, 왼쪽 민트는 위↔가운데.
  발판에 서면 슝 하고 양방향으로 갑니다.
- **윗동네** 에 여섯 채 — 방방 · 구름노래방 · 미니게임장 · 방탈출 · 구름영화관 · 천문대.
  - **방방** — 큰 트램폴린 위에 올라서면 저절로 통통 뜁니다. 미러볼도 돌아요.
  - **구름노래방** — 코인노래방처럼 어둡게. 소파 · 노래방 기계 · 큰 화면 · 미러볼.
  - **미니게임장** — 방구게임(참기) · 타자게임(20초) · 속도게임(반응속도). 최고 기록은 브라우저에 남아요.
  - **천문대** — 망원경을 누르면 별 화면이 가득 차고, 바닥 자리에 누울 수도 있습니다.
  - **구름영화관** — 큰 스크린과 옆 벽 상영표. **아무나 틀 수 있고, 트는 순간 끝날 때까지
    아무도 못 바꿉니다**(막는 건 서버라 화면을 고쳐도 소용없어요). 늦게 들어와도 같은 지점부터
    따라붙고, 자동재생 때문에 소리는 처음에 꺼져 있어 한 번 눌러 켜면 됩니다.
    영상 올리기는 호스트만 — 60MB 이하, music 보관함에 `vid:제목|초` 로 담습니다.
  - 방탈출은 아직 얼개만.
- 윗동네 **🪧 팻말** — "여기 뭐 만들지..?" 를 눌러 뭘 더 지으면 좋을지 적을 수 있어요.
- 호스트 **테스트 관리** 목록은 **최근에 들어온 순**이고 들어온 시각이 같이 나옵니다.
- **구름옷가게** 전신거울 앞에서 얼굴 · 머리 · 옷 색을 바꿉니다. 머리와 옷 색은 별로 사요.
  고른 모습은 이 기기에 저장되고 같이 접속한 사람들에게도 그대로 보입니다.
- 호스트는 **⚙ 설정 → 🎨 캐릭터 이미지**에서 사진을 올릴 수 있어요. 올린 사진은 옷가게 '얼굴' 칸에
  값과 함께 나타나고, 산 사람의 캐릭터가 그 사진으로 바뀝니다(마을에서도, 다른 사람 화면에서도).
  올릴 때 **배경 지우기(누끼)** 가 기본으로 켜져 있습니다. 가장자리부터 비슷한 색을 지우는 방식이라
  배경이 단색에 가까울수록 잘 되고, 슬라이더로 세기를 맞출 수 있어요.
- 호스트는 별 300개를 들고 시작합니다 (옷가게 물건을 다 시험해볼 수 있게).
- 옷가게 오른쪽 **📮 우체통** — "생겼으면 하는 캐릭터를 적어주세요!" 에 적은 것이 **회차별로** 남습니다.
  호스트는 우체통에서 '전체 보기'로 지난 회차까지 몰아 보고, 하나씩 지울 수 있어요.
- 투두리스트 아래 **📮 피드백** — 익명입니다. 이름도 기기 표식도 안 남고, 목록은 호스트만 봅니다.
- 투두리스트를 **다 깨면 별 100개**를 줍니다. 입장할 때 뜨는 환영 팝업에도 적혀 있어요.
- 마우스 커서도 픽셀입니다 — 평소엔 흰 화살표, 누를 수 있는 것 위에서는 노란 별.
  ⚙ 설정에서 끌 수 있어요 (`픽셀 커서 쓰기`).

**새 기능을 넣으면 투두리스트에도 바로 항목을 추가합니다.**
- 카페 의자에 앉으면 **직원이 테이블까지 걸어와서** 말을 걸어요. 한 테이블에 둘이 앉으면 둘이 스몰토크를 합니다.
- **모바일** — 가로로 눕히면 왼쪽 아래 조이스틱, 오른쪽 아래 들어가기 · 채팅 버튼.
  세로로 들면 "가로로 돌려주세요" 안내가 뜹니다. 화면이 낮으면 자동으로 축소해 시야를 확보해요.

## 테스트 입장 (Supabase)

**인원 제한은 없습니다.** 문을 여닫는 건 호스트의 비공개 모드로 합니다.

- 입장 화면 위쪽 캐릭터 줄은 **지금 들어와 있는 사람 수**만큼 늘어납니다.
- **호스트로 들어오려면** 입장 화면에서 "호스트로 입장하기"를 눌러 호스트 코드를 넣으세요.
- 호스트 화면 우측 **테스트 관리 → 비공개 모드 켜기** 를 누르면 그때부터 호스트만 들어올 수 있어요.
  이미 들어와 있는 사람은 그대로 남습니다. 다 내보내려면 **다음 회차로 넘기기**.
- 같은 기기에서 새로고침하면 원래 자리로 돌아옵니다.
- **이어하기** — 별·꾸민 모습·산 것·투두는 **이 브라우저에** 남습니다(localStorage). 서버로는 안 보내요.
  같은 브라우저로 다시 오면 이어집니다. 다른 브라우저·기기는 따로 시작해요.
  위치와 들고 있던 것은 저장하지 않습니다. ⚙ 설정의 `이 브라우저 기록 지우기` 로 초기화.

입장 판정은 전부 Postgres 함수(`cc_join`)에서 하고, 테이블은 RLS 로 직접 접근을 막아뒀습니다.

### 새 환경에서 설정하기

1. `.env.example` 를 복사해 `.env.local` 을 만들고 값을 채웁니다.
2. Supabase 대시보드 → SQL Editor 에 `supabase/schema.sql` 을 붙여넣고 Run.
3. 배포용으로 저장소 Secrets 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 등록.

호스트 코드 기본값은 `cloudhost1234` 입니다. 바꾸려면:

```sql
update public.cc_config set host_code = '새코드' where id = 1;
```

publishable(anon) key 는 공개돼도 되는 값이지만, 그래서 **RLS 를 반드시 켜야** 합니다.
`service_role` 키는 프론트엔드에 절대 넣지 마세요.
